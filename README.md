# Dance With Ms. Karen Static Landing Page

This is a polished static landing page with:

- `index.html`
- `style.css`

## How to preview

Open `index.html` in any browser.

## How to customize

In `index.html`, replace:

- `hello@dancewithmskaren.com` with your real email
- `PunchPass Link` button `href="#"` with your real PunchPass URL
- Any placeholder class ages, pricing, or schedule notes
- The decorative music-note hero card with a real image/logo if desired

## Suggested next edits

- Add your actual logo image
- Add class schedule
- Add location
- Add Instagram link
- Add registration/PunchPass URL
